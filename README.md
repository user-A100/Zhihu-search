# 知藏

一个本地优先的知乎收藏工具，包含 Chrome / Edge 扩展和 Android 阅读器：

- 浏览器扩展负责同步、搜索和整理知乎收藏，并可将回答或文章写入 Obsidian；
- Android 阅读器负责随机重温、按收藏顺序浏览、搜索、阅读进度和浏览历史。

所有收藏索引和阅读记录都保存在当前设备，不需要知藏服务器。

## 为什么从浏览器扩展开始

原项目 [`wang2028/zhihu`](https://github.com/wang2028/zhihu) 的思路是：爬取收藏夹，生成本地数据文件，再用一个本地网页全文搜索。它发布于较早的知乎接口时期，依赖 Node 10、旧版页面结构和一个已经不应继续依赖的第三方远端服务。

知藏保留“本地收藏索引 + 搜索”的核心，但改成浏览器扩展：

- 直接使用你已经登录知乎的浏览器会话，不复制、不保存 Cookie；
- 收藏索引与剪藏标记只写入 `chrome.storage.local`；
- 搜索结果始终打开真正的知乎页面，简悦的知乎适配规则可以照常工作；
- 在知乎内容页点击右下角“收藏并剪藏”，会使用当前或第一个可用的知乎收藏夹、导入 Obsidian，并在成功后自动标记“已剪藏”。
- 也可以不经过简悦，直接把单篇内容转换为 Markdown 写入 Obsidian 文件夹。

## 浏览器扩展安装

1. 下载或克隆本仓库。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本仓库根目录。如果已经加载过，请点击扩展卡片上的“重新加载”。
5. 固定“知藏”扩展，点击图标打开仪表盘。

## 使用

1. 先在同一个浏览器登录知乎。
2. 点击右上角“同步设置”，输入单个收藏夹地址，例如 `https://www.zhihu.com/collection/959441365`；也可以输入个人主页，一次同步该主页下可读取的全部收藏夹。
3. 后续仍通过“同步设置”更换地址或重新同步；正文主页不再重复显示地址输入框。
4. 同步完成后，可搜索标题、作者、摘要、正文和收藏夹名称；“多级搜索”还能使用并且、或者、不含关系逐层下探。
5. 点击右上角“导出到手机”，可以下载包含当前收藏库的知藏 JSON 数据包。
6. 如需继续使用简悦，点击“打开知乎原文”，在知乎页面完成简悦导出。
7. 点击页面右下角“收藏并剪藏”，或按 `Alt+Shift+M`。知藏会收藏当前内容、写入 Obsidian，并在写入成功后自动标记。

仪表盘可以按“全部内容 / 待剪藏 / 已剪藏”和收藏夹筛选。结果默认每页 20 篇，可切换为 50 或 100 篇。再次同步不会清除已有标记。

## 把收藏库带到手机

移动端不再尝试登录知乎，也不会调用知乎收藏接口。数据通过一个本地文件在电脑和手机之间传递：

1. 在电脑浏览器中登录知乎，用知藏扩展完成收藏同步。
2. 在知藏仪表盘右上角点击“导出到手机”，得到 `知藏收藏-YYYY-MM-DD.json`。
3. 通过数据线、网盘、微信文件传输助手或其他方式把文件发送到手机。
4. 在知藏 App 顶栏或“我的”页点击“载入”，选择这个 JSON 文件。
5. 知藏核对文件格式、版本和文章数量后，再把收藏库写入手机本地存储。

之后更新收藏库时，重新在电脑导出并在手机载入即可。新数据包会替换手机上的收藏内容，但会保留相同文章的阅读进度和浏览历史。数据包包含收藏正文，是可直接阅读的明文 JSON 文件，请像个人笔记一样妥善保管。

## 直接导出到 Obsidian

1. 在任意搜索结果中点击“存入 Obsidian”。
2. 首次使用时，浏览器会要求选择文件夹。请选择 Obsidian 仓库根目录，或仓库内专门存放知乎内容的子文件夹。
3. 知藏会把正文转换为带 YAML 属性的 `.md` 文件，并直接写入所选文件夹。
4. 写入成功后，该内容会自动标记为“已剪藏”；再次点击可以更新同一个 Markdown 文件。

在知乎回答或文章页也可以直接点击右下角“收藏并剪藏”。如果知乎弹出收藏夹面板，知藏会保留当前选中项；没有选中项时使用第一个可用收藏夹。首次使用或文件夹权限失效时，会打开一次知藏授权页，选择/授权后会继续本次导入。

每条结果左侧可以勾选。“导入所选”会批量处理已勾选内容；“仅导入未剪藏”会处理当前关键词、多级条件、收藏夹和剪藏状态共同命中、且尚未标记为已剪藏的全部内容，不受当前页限制，适合日常增量导入。“重新导入全部结果”会包含已剪藏内容并在执行前提醒确认。批量导入会显示已完成数量和百分比，失败项会保留选中以便重试。

需要更改导出位置时，点击右上角“同步设置”，在“Obsidian 导出文件夹”中选择新的仓库或子文件夹。更改只影响之后的导出，不会移动或删除原文件夹中的 Markdown。

导出的 Markdown 包含标题、作者、知乎原文、所属收藏夹、保存时间、GFM 表格、代码块和常见知乎公式。图片暂时保留为远程链接，不会下载到附件目录。

目录权限由 Chrome / Edge 的 File System Access API 管理。知藏只保存浏览器提供的目录句柄，不读取 Obsidian 中其他笔记，也不会上传文件内容。

## 与简悦的边界

知藏现在可以完成基础的“正文 → Markdown → Obsidian 文件夹”链路。简悦仍然更适合复杂网页适配、标注、图片本地化和定制化导出。

如果继续使用简悦同步助手，可保持原来的导出目录；知藏的手动标记和直接导出可以并存。

## 移动端阅读器 MVP

仓库内已经包含独立的知藏移动端界面，专注于更舒适地查看、搜索和重温知乎收藏，不包含 Obsidian 导出功能。

目前包含：

- 记录曝光次数的随机推荐流，优先翻出较少出现的旧收藏；
- 带本地进度的“藏签”继续阅读；
- 按收藏时间倒序的收藏库，并可按收藏夹筛选；
- 标题、作者、正文和收藏夹全文搜索；
- 沉浸阅读、字号调整、已读状态和浏览历史；
- 320px 起的移动端响应式布局。

本地查看带演示数据的版本：

```powershell
npm run preview:mobile
```

然后访问 `http://127.0.0.1:4173/src/mobile.html?demo=1`。移除 `?demo=1` 后，可以在页面中载入由电脑知藏导出的 JSON 数据包。Android App 使用独立的原生本地存储，不会自动共享桌面扩展的数据。

### Android App

Android 工程位于 `android/`，通过 Capacitor 包装移动端阅读界面。首次安装后，点击顶栏“载入”，选择电脑知藏导出的 JSON 数据包即可。App 不包含知乎登录页、Cookie 会话或收藏接口请求桥接。

构建需要 Node.js、完整 JDK 21 和 Android SDK Platform 36。Android Studio 不是生成 APK 的必需项；只有需要图形化调试、模拟器或直接打开工程时才需要安装。

在 Windows 项目根目录执行：

```powershell
npm install
npm run mobile:apk
```

构建脚本会先生成移动端 Web 资源、同步 Capacitor 工程，再编译调试 APK。成功后安装包位于：

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

连接已开启 USB 调试的 Android 手机后，可以安装：

```powershell
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

Windows 构建脚本会优先复用 `D:\Android\Jdk\21`、`D:\Android\Sdk` 和 `D:\Android\Gradle`，找不到时再读取 `JAVA_HOME`、`ANDROID_HOME` 和 `GRADLE_USER_HOME`。如果检测到本机 `127.0.0.1:7890` 代理，会仅为本次 Gradle 下载临时启用该代理。

需要使用 Android Studio 时执行：

```powershell
npm run mobile:android
```

## 隐私与限制

- 不收集或上传收藏内容、Cookie、Obsidian 路径和阅读记录。
- 手机数据包完全由用户手动导出、传输和载入，知藏不提供云端中转。
- 知乎接口可能随时调整；如果同步突然失败，请先确认知乎登录状态和验证码，再检查接口结构是否变化。
- 私密收藏能否读取取决于当前知乎账号权限。
- 大型收藏库的首次同步需要逐页请求，请避免频繁重复同步，以免触发知乎风控。
- 当前标记存放在本机浏览器配置中；清除扩展数据会同时清除标记。
- 浏览器目录权限可能在重启后需要重新确认，这是 Chrome / Edge 的安全机制。

## 第三方组件

Markdown 转换使用 MIT 许可的 [Turndown](https://github.com/mixmark-io/turndown) 与 `turndown-plugin-gfm`。许可文件保存在 `src/vendor/turndown/`。

```powershell
npm test
npm run check
npm run mobile:apk
```

浏览器扩展不依赖打包器，修改后在扩展管理页点击“重新加载”即可。Android 工程通过 Capacitor 构建，首次下载依赖较慢，之后会复用 Gradle 缓存。
