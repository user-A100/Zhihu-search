# 知藏

一个本地优先的 Chrome / Edge 扩展：同步并搜索自己的知乎收藏，将回答或文章直接转换为 Markdown 写入 Obsidian，并记录处理状态。

## 为什么做成浏览器扩展

原项目 [`wang2028/zhihu`](https://github.com/wang2028/zhihu) 的思路是：爬取收藏夹，生成本地数据文件，再用一个本地网页全文搜索。它发布于较早的知乎接口时期，依赖 Node 10、旧版页面结构和一个已经不应继续依赖的第三方远端服务。

知藏保留“本地收藏索引 + 搜索”的核心，但改成浏览器扩展：

- 直接使用你已经登录知乎的浏览器会话，不复制、不保存 Cookie；
- 收藏索引与剪藏标记只写入 `chrome.storage.local`；
- 搜索结果始终打开真正的知乎页面，简悦的知乎适配规则可以照常工作；
- 简悦导出成功后，可在知乎页面右下角标记“已剪藏”，仪表盘立即同步状态。
- 也可以不经过简悦，直接把单篇内容转换为 Markdown 写入 Obsidian 文件夹。

## 安装

1. 下载或克隆本仓库。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本仓库根目录。如果已经加载过，请点击扩展卡片上的“重新加载”。
5. 固定“知藏”扩展，点击图标打开仪表盘。

## 使用

1. 先在同一个浏览器登录知乎。
2. 点击右上角“同步设置”，输入单个收藏夹地址，例如 `https://www.zhihu.com/collection/959441365`；也可以输入个人主页，一次同步该主页下可读取的全部收藏夹。
3. 后续仍通过“同步设置”更换地址或重新同步；正文主页不再重复显示地址输入框。
4. 同步完成后，可搜索标题、作者、摘要、正文和收藏夹名称；“多级搜索”还能使用并且、或者、不含关系逐层下探。
5. 如需继续使用简悦，点击“打开知乎原文”，在知乎页面完成简悦导出。
6. 确认进入 Obsidian 后，点击页面右下角“标记为已剪藏”，或按 `Alt+Shift+M`。

仪表盘可以按“全部内容 / 待剪藏 / 已剪藏”和收藏夹筛选。结果默认每页 20 篇，可切换为 50 或 100 篇。再次同步不会清除已有标记。

## 直接导出到 Obsidian

1. 在任意搜索结果中点击“存入 Obsidian”。
2. 首次使用时，浏览器会要求选择文件夹。请选择 Obsidian 仓库根目录，或仓库内专门存放知乎内容的子文件夹。
3. 知藏会把正文转换为带 YAML 属性的 `.md` 文件，并直接写入所选文件夹。
4. 写入成功后，该内容会自动标记为“已剪藏”；再次点击可以更新同一个 Markdown 文件。

每条结果左侧可以勾选。“导入所选”会批量处理已勾选内容；“导入全部结果”会处理当前关键词、多级条件、收藏夹和剪藏状态共同命中的全部内容，不受当前页限制。批量导入会显示已完成数量和百分比，失败项会保留选中以便重试。

需要更改导出位置时，点击右上角“同步设置”，在“Obsidian 导出文件夹”中选择新的仓库或子文件夹。更改只影响之后的导出，不会移动或删除原文件夹中的 Markdown。

导出的 Markdown 包含标题、作者、知乎原文、所属收藏夹、保存时间、GFM 表格、代码块和常见知乎公式。图片暂时保留为远程链接，不会下载到附件目录。

目录权限由 Chrome / Edge 的 File System Access API 管理。知藏只保存浏览器提供的目录句柄，不读取 Obsidian 中其他笔记，也不会上传文件内容。

## 与简悦的边界

知藏现在可以完成基础的“正文 → Markdown → Obsidian 文件夹”链路。简悦仍然更适合复杂网页适配、标注、图片本地化和定制化导出。

如果继续使用简悦同步助手，可保持原来的导出目录；知藏的手动标记和直接导出可以并存。

## 隐私与限制

- 不收集或上传收藏内容、Cookie、Obsidian 路径。
- 知乎接口可能随时调整；如果同步突然失败，请先确认知乎登录状态和验证码，再检查接口结构是否变化。
- 私密收藏能否读取取决于当前知乎账号权限。
- 大型收藏库的首次同步需要逐页请求，请避免频繁重复同步，以免触发知乎风控。
- 当前标记存放在本机浏览器配置中；清除扩展数据会同时清除标记。
- 浏览器目录权限可能在重启后需要重新确认，这是 Chrome / Edge 的安全机制。

## 第三方组件

Markdown 转换使用 MIT 许可的 [Turndown](https://github.com/mixmark-io/turndown) 与 `turndown-plugin-gfm`。许可文件保存在 `src/vendor/turndown/`。


扩展不依赖打包器或第三方运行时库，修改后在扩展管理页点击“重新加载”即可。
